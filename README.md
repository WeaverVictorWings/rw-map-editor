# 铁锈地图编辑器

一个专门编辑 **铁锈战争（Rusted Warfare）** 地图的轻量编辑器（非官方）。安卓优先，之后出 Windows 版。

- 画地形时**自动加过渡**：选“草地、水、沙地”直接画，不同地形之间自动垫上中间地形（比如草地和水之间会出现泥土、沙地、浅滩），不用再手动点“自动铺图”。
- **物品**：资源池（3×3）、大岩石、树、草丛、碎石等，按图块集里的标注自动生成。
- **出生点**：点一下就放好 1 个指挥中心 + 2 个建造者，队伍号自动排。
- **对称绘制**：左右、上下、中心、四向，地形、物品、出生点都支持。
- **能玩吗？检查**：map_info、地面空格、未定义图块、水面属性、出生点、地图尺寸等，能一键修的直接修。
- **新建地图向导**：选尺寸、人数、布局、底色地形，自动生成出生点、资源池和 map_info。
- 撤销/重做、小地图、每 30 秒自动保存（闪退后可恢复）、导出预览图（`名称_map.png`）。
- **原样往返**：打开后不改动直接保存，图层数据逐字节一致；没改的属性、对象、图块集都保留。

## 图块素材

编辑器**不附带游戏素材**。第一次使用时打开一张你已有的地图（地面图块集内嵌图片的那种，游戏或 NotTiled 导出的一般都是），编辑器会从里面取出地面、物品、单位三个图块集，保存在本机，之后新建地图就用这套素材。

## 下载安卓版

每次推送到 `main` 分支，GitHub Actions 会自动构建 APK：

1. 打开仓库的 **Actions** 页面，点最新一次成功的「安卓 APK」。
2. 页面底部 **Artifacts** 里下载 `rw-map-editor-android`（是个 zip），解压出 `.apk`。
3. 传到手机上安装（需要允许“安装未知来源应用”）。

> 没有配置签名密钥时构建的是调试版，每次构建的签名都不同，**装新版前要先卸载旧版**（会清掉本机的自动保存和图块素材，重新打开一张地图即可）。
> 想直接覆盖升级，可以在仓库 Settings → Secrets 里配置 `ANDROID_KEYSTORE_BASE64`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD`，之后会构建签名的正式版。

## 在电脑上试用 / 开发

不需要安装任何依赖，网页部分是纯 JavaScript：

```bash
python3 -m http.server 8765 --directory www
# 浏览器打开 http://localhost:8765
```

自动化测试（需要 Playwright）：

```bash
node tests/smoke.mjs 你的地图.tmx 输出目录
```

## 目录

| 路径 | 内容 |
| --- | --- |
| `www/js/tmx.js` | TMX 读写（base64 + zlib/gzip、翻转位、内嵌图片），只改动编辑器管理的部分 |
| `www/js/terrain.js` | 地形自动过渡：角点地形网格 + 邻接图最短路径插入中间地形 |
| `www/js/render.js` | 64×64 分块渲染、整图概览、小地图 |
| `www/js/editor.js` | 撤销、工具、对称、物品、出生点、map_info |
| `www/js/check.js` | “能玩吗？”检查、资源分布、预览图 |
| `www/js/app.js` | 界面与手势 |
| `android-plugin/` | 安卓“另存为”原生插件 |
| `scripts/patch-android.mjs` | 生成安卓工程后加入插件 |

## 已知限制

- 游戏规则来自社区整理（map_info 的完整属性表、悬崖类属性的精确含义、`[pN]` 前缀是否决定人数都没有官方说明），检查结果以游戏里实际打开为准。
- 超过 1500×1500 的地图在手机上很吃内存；5000×5000 在电脑浏览器里约占 0.5GB。
- 资源分布报告按直线距离估算，不考虑绕路。
