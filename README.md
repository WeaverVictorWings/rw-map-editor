# 铁锈地图编辑器 2.0

一个专门编辑 **铁锈战争（Rusted Warfare）** 地图的编辑器（非官方）。安卓 App 为主，电脑上用浏览器打开同样能用。

目标：**新手几分钟能做出一张能玩的图，老手能做大图、城夺、生存、任务图。**

## 主要功能

**画地图**
- 地形画笔：选“草地、水、沙地”直接画，地形之间**自动加过渡**（草地和水之间自动出现沙滩、浅滩），不用自己拼图块。
- 主笔 / 副笔（右键或开关画副笔）、“只覆盖某种地形”、矩形、椭圆、油漆桶（可全图同种地形一起换）、吸管。
- 物品：资源池、大岩石、树、草丛……；**随机笔刷**按比例撒几种物品。
- 出生点：点一下放好指挥中心 + 2 个建造者，队伍号自动排；**最多 100 队**（游戏引擎上限）。
- 对称绘制：左右、上下、中心、四向，地形、物品、出生点、粘贴都支持。

**整块、整图操作**
- 框选、魔棒 → 复制、剪切、粘贴、翻转、旋转、存为印章。
- **印章库**：标准基地、资源点、湖泊、浅滩、森林、高地、岩浆……一点就放；自己的印章可以导出分享。
- **等比缩放**：整张图 ×0.5～×4，地形重铺，出生点、资源池智能搬家，资源池可按面积增加。
- **整图镜像**：画好半张图，一键变成左右 / 上下 / 中心 / 四向对称图；**对称差异检查**用红色标出不对称的地方。
- **随机生成**：大陆、群岛、海洋、河流、高原 × 温带、雪地、沙漠、火山，带**分享码**，别人输入同一个码能生成同一张图。
- **图片转地图**：自动找主色，你决定每种颜色变成什么地形、各占多少比例；点预览图任意一块可以单独改（锁定）；也能按亮度当高度图用，或只当描图参考。
- **立绘贴图**：把图片切成小块嵌进地图；**描图参考图**：半透明叠在地图上照着画。

**触发器（可视化）**
- 每个触发器是一张“**当……就……**”卡片，顶上一句大白话说明它在干什么；字段都是下拉框、开关、数字框，不用手写属性。
- **逻辑图**：所有触发器怎么连在一起（激活 / 关闭），点方块直接编辑。
- 模板：**城市争夺**（中立守军刷新、各队占领检测、占领加钱、城名随占领方变色）、**生存模式**（波次表格 + 敌军出生点）、**任务关卡**（按顺序出现的目标和箭头提示）、常用积木（开局资金、定时刷兵、进入区域提示……）。
- 触发器检查：引用不存在、队伍号写成 none、时间写成纯数字（毫秒）、区域大小为 0、胜利条件写错等。

**检查和保存**
- “能玩吗？”检查：map_info、地面空格、出生点压水、资源池太挤、队伍超过 10 / 100、触发器问题……能修的一键修。
- **平衡报告**：按陆军实际步行路线比较各队资源和地盘；叠加图显示陆军 / 海军 / 悬浮通行、可建造区域、各队地盘。
- **保存到游戏文件夹**（授权一次，地图和预览图一起存进去）、最近打开、自动保存、快照、历史面板（点一下回到任意一步）。
- 预览图（200 / 500 像素）和带图例的**展示图**。

**上手**
- 每个工具旁边都有 **?**，点开就是通俗说明；**新手教程** 4 课，跟着做，自动高亮下一步要点的按钮。
- **Ctrl+K 功能搜索**：输入“镜像”“资源池”就能找到功能。
- 手机：单指画、双指拖动缩放、**双指轻点撤销、三指轻点重做**。

## 下载

在仓库的 **Releases** 页面下载：

- `rw-map-editor.apk`：安卓版。2.0 起使用**固定签名**，以后的新版可以直接覆盖安装。
  > 从 1.x 测试版升级到 2.0 需要先卸载一次旧版（旧版每次构建签名都不同）。
- `rw-map-editor-web.zip`：电脑版。解压后双击 `Start-Editor.bat`，会自动用浏览器打开编辑器（不用装任何东西；关掉黑色窗口就停止）。推荐 Chrome 或 Edge。

## 图块素材

编辑器**不附带游戏素材**。第一次使用时打开一张你已有的地图（地面图块集内嵌图片的那种，游戏或 NotTiled 导出的一般都是），编辑器会从里面取出地面、物品、单位三个图块集，保存在本机，之后新建地图就用这套素材。

## 关于玩家人数

游戏引擎最多支持 **100 支队伍**。但普通房间只有 **10 队**：第 11 队以后的单位和触发器会被游戏跳过。人数多的地图需要支持更多玩家的服务器房间（例如 RW-HPS 调大 `maxPlayer`，或 `P20` 这类中继房间）。编辑器会在检查里提示。

## 开发

网页部分是纯 JavaScript，不需要构建：

```bash
python3 -m http.server 8765 --directory www   # 浏览器打开 http://localhost:8765
```

自动化测试（需要 Playwright）：

```bash
node tests/smoke.mjs 地图.tmx 输出目录      # 读写往返、地形、撤销、5000×5000 压力
node tests/extra.mjs 地图.tmx 输出目录      # 边界情况
node tests/v2.mjs 地图.tmx 输出目录         # 2.0 界面、框选粘贴、触发器模板、缩放
node tests/v2b.mjs 地图.tmx 图片.png 输出目录 # 生成、图片转地图、贴图、印章、历史、教程
node tests/v2m.mjs 地图.tmx 输出目录        # 手机触屏手势
```

| 路径 | 内容 |
| --- | --- |
| `www/js/tmx.js` | TMX 读写（base64 + zlib/gzip、翻转位、内嵌图片），没改的部分原样保留 |
| `www/js/terrain.js` | 地形自动过渡：角点地形网格 + 地形邻接图 |
| `www/js/history.js` | 撤销记录（大改动自动转成整层快照） |
| `www/js/editor.js` | 工具、对称、物品、出生点、map_info |
| `www/js/transform.js` | 选区、复制粘贴、翻转旋转、整图镜像、对称检查、等比缩放 |
| `www/js/triggers.js` | 可视化触发器：类型定义、白话描述、检查、模板、逻辑图 |
| `www/js/gen.js` `terraform.js` `imagemap.js` | 随机生成、出生点/资源池摆放、图片转地图 |
| `www/js/pathing.js` | 通行图、步行距离、平衡报告 |
| `www/js/render.js` | 分块渲染、整图概览、叠加图、小地图 |
| `www/js/panels.js` `input.js` `actions.js` | 界面、手势与快捷键、菜单和功能搜索 |
| `www/js/help.js` `tutorial.js` `icons.js` | “?”说明、新手教程、图标 |
| `android-plugin/` | 安卓原生插件（另存为、游戏文件夹）和固定签名 |

## 已知限制

- 游戏规则来自游戏代码和社区整理，检查结果以游戏里实际打开为准。
- 超过 1500×1500 的地图在手机上很吃内存；5000×5000 在电脑浏览器里约占 0.7GB。
- 签名密钥是公开的，只用来保证每次构建签名一致；如需私有签名，在仓库 Secrets 里配置 `ANDROID_KEYSTORE_BASE64` 等即可自动改用。
