# 功能总览

这里是完整功能列表。第一次使用请先看 [README](../README.md)。

## 地图编辑器

**画地图**
- 地形画笔：选“草地、水、沙地”直接画，地形之间**自动加过渡**（草地和水之间自动出现沙滩、浅滩），不用自己拼图块。
- 主笔 / 副笔（右键或开关画副笔）、“只覆盖某种地形”、矩形、椭圆、油漆桶（可全图同种地形一起换）、吸管。
- 物品：资源池（默认 1 格，可选 3×3 带边框）、大岩石、树、草丛……；**随机笔刷**按比例撒几种物品。
- 出生点：点一下放好指挥中心 + 2 个建造者，队伍号自动排；**最多 100 队**（游戏引擎上限）。
- 对称绘制：左右、上下、中心、四向，地形、物品、出生点、粘贴都支持。

**整块、整图操作**
- 框选、魔棒 → 复制、剪切、粘贴、翻转、旋转、存为印章。
- **印章库**：标准基地、资源点、湖泊、浅滩、森林、高地、岩浆……一点就放；自己的印章可以导出分享。
- **等比缩放**：整张图 ×0.5～×4，地形重铺；单位、资源池只搬位置、绝不复制（单位可选原地不动，资源池可选按面积增加）。
- **整图镜像**：画好半张图，一键变成左右 / 上下 / 中心 / 四向对称图；**对称差异检查**用红色标出不对称的地方。
- **随机生成**：大陆、群岛、海洋、河流、高原 × 温带、雪地、沙漠、火山，带**分享码**，别人输入同一个码能生成同一张图。
- **图片转地图**：自动找主色，你决定每种颜色变成什么地形、各占多少比例；点预览图任意一块可以单独改（锁定）；也能按亮度当高度图用，或只当描图参考。
- **立绘贴图**：把图片切成小块嵌进地图；**描图参考图**：半透明叠在地图上照着画。

**触发器（可视化）**
- 每个触发器是一张“**当……就……**”卡片，顶上一句大白话说明它在干什么；字段都是下拉框、开关、数字框，不用手写属性。
- **逻辑图**：所有触发器怎么连在一起（激活 / 关闭），点方块直接编辑。
- 模板：**城市争夺**（中立守军刷新、各队占领检测、占领加钱、城名随占领方变色）、**生存模式**（波次表格 + 敌军出生点）、**任务关卡**（按顺序出现的目标和箭头提示）、常用积木（开局资金、定时刷兵、进入区域提示……）。
- 触发器检查：引用不存在、队伍号写成 none、时间写成纯数字（毫秒）、区域大小为 0、胜利条件写错等。

**检查和保存**
- “能玩吗？”检查：map_info、地面空格、出生点压水、资源池太挤、队伍超过 10 / 100、触发器问题……能修的一键修。
- **平衡报告**：按陆军实际步行路线比较各队资源和地盘；叠加图显示陆军 / 海军 / 悬浮通行、可建造区域、各队地盘。
- **保存到游戏文件夹**（授权一次，地图和预览图一起存进去）、最近打开、自动保存、快照、历史面板（点一下回到任意一步）。
- **地图封面**（和地图同名的 .png，保存时默认一起导出）和带图例的**展示图**。整图操作前自动存快照。

**自动丰富细节（2.2）**
- 30 个预设：10 种地形风格（草原、森林、沙漠、雪原、火山、沼泽、群岛、战损、峡谷、三角洲）、7 种基地 / 据点印章、9 种新建地图布局、4 套触发器积木；也能存自己的预设并用分享码互传。
- 10 种用法：一键整图、修改器堆叠、并排 4 个版本挑一个、群系笔刷、自定义规则、学习参考地图、高度笔刷、道路工具、战术模块、整图换主题。
- 色块：调色板（RGB / 色相饱和度亮度 / 色号 / 吸管）调任意颜色，选它在游戏里的性质（陆地、浅滩、浅水、深水、不可通行、岩浆）。
- 物品笔刷带形状（矩形、椭圆、直线、油漆桶）、密度和最小间距；单位面板带图标、分类、搜索，可一次放一排或方阵。
- 文字工具（mapText，编辑器里直接显示）、作战日志编辑器、地图文字多语言版本。

**大功能（2.2）**
- 开局推演（各队几秒遇敌、接战线）、地图拼接、从别的地图复制、地图库、批量处理、打包地图合集（.rwmod）、版本对比、Mod 支持（读取 Mod 的单位和图块集）。
- 试玩检查清单（带每次测试记录）、地图体检评分、导出 / 导入个人数据、色盲友好配色。

**2.6 新增**
- **Mod 编辑器工具集**：复制 / 变体 / 数值缩放 / 向导 / 武器模板，对比表、散点图、战斗模拟、建造树、引用改名，炮塔位置拖拽，更新日志、评分修复、素材检查。

**2.5 新增**
- **Mod 编辑器（第一阶段）**：打开 `.rwmod`/zip/文件夹，浏览单位，表单或源码编辑，检查问题，打包 `.rwmod`。

**2.4 新增**
- 资源池按 1×1 处理（可紧挨着放）、**一键平衡**、设计向导、曲线画河画路、平滑 / 侵蚀 / 噪声笔刷、粘贴边缘羽化、吸附与精密绘图。
- **触发器模拟器**（不进游戏看每个触发器几秒触发）、触发器模板库、火力覆盖分析、通行瓶颈图、海战检查、测距与射程圈。
- 批量编辑单位、批量替换、查找并跳转、图层面板、区域管理器、撤销历史面板、多张参考图、队伍颜色与联盟。
- 工坊发布包、一键地图简介、截图导出、工程文件（.rwproj）、自动备份、离线网页版（PWA）、手机体验模式。

**界面语言（2.2）**
- 简体中文、English、Русский、Português (BR)、Español、Bahasa Indonesia、Türkçe、繁體中文、Українська、Français、日本語。第一次打开按系统语言自动选择，可在“设置”里切换。
- 英文和繁体中文是全量翻译；其他语言翻译了 2.3 之前的菜单、按钮和短句，**2.4 新增功能的文字暂时显示英文**，个别长段说明也是英文。

**上手**
- 每个工具旁边都有 **?**，点开就是通俗说明；**新手教程** 4 课，跟着做，自动高亮下一步要点的按钮。
- **Ctrl+K 功能搜索**：输入“镜像”“资源池”就能找到功能。
- 手机：单指画、双指拖动缩放、**双指轻点撤销、三指轻点重做**。

## 图块素材

编辑器**不附带游戏素材**。第一次使用时打开一张你已有的地图（地面图块集内嵌图片的那种，游戏或 NotTiled 导出的一般都是），编辑器会从里面取出地面、物品、单位三个图块集，保存在本机，之后新建地图就用这套素材。

## 关于玩家人数

游戏引擎最多支持 **100 支队伍**。但普通房间只有 **10 队**：第 11 队以后的单位和触发器会被游戏跳过。人数多的地图需要支持更多玩家的服务器房间（例如 RW-HPS 调大 `maxPlayer`，或 `P20` 这类中继房间）。编辑器会在检查里提示。

## 已知限制

- 游戏没有“不可建造”这种地块性质，所以色块没有这一项（“不可通行”的色块同样不能建造）。
- 打包合集（mod-info.txt + maps 文件夹）按社区常见写法，Mod 单位放进地图后需要玩家装同一个 Mod；发布前请在游戏里试一次。不支持 RAR 格式的 Mod，请先解压再打包成 zip。
- 开局推演的时间是按大致移动速度估算的，误差约几秒到十几秒。

- 游戏规则来自游戏代码和社区整理，检查结果以游戏里实际打开为准。
- 超过 1500×1500 的地图在手机上很吃内存；5000×5000 在电脑浏览器里约占 0.7GB。
- 签名密钥是公开的，只用来保证每次构建签名一致；如需私有签名，在仓库 Secrets 里配置 `ANDROID_KEYSTORE_BASE64` 等即可自动改用。
