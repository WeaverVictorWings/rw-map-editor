## A. 触发器编辑器补全(来自 PDF)
1. ★ 触发器类型下拉补全 camera_pan / fall / objective / attack_point 的专属表单(www 里没有 camera_pan)【缺】
2. ★ unitDetect 的 11 个单位限定(onlyIdle/onlyBuildings/onlyMainBuildings/onlyEmptyQueue/onlyBuilders/onlyOnResourcePool/onlyAttack/onlyAttackAir/onlyTechLevel/includeIncomplete/unitType)做成一组"限定"勾选卡,并附大白话说明【弱】
3. ★ 属性旁加"这是什么"气泡(delay vs warmup、repeatDelay vs resetActivationAfter、allToActivate vs activatedBy),直接引用教程里的区分
4. ★ delay/warmup 输入框支持"13s / 13000 / 1m"互转并实时提示毫秒值(PDF 里 13000=13 秒的坑)
5. alsoActivate 与 id 配对可视化:点 id 高亮所有 alsoActivate 同值的触发器
6. spawnUnits 编辑器:选单位 + 数量 + 预览占格(bugBee*25 格式),带按阵营分组的单位库(陆军/机械/空军/海军/虫族/建筑,按 PDF 末尾单位表)
7. 单位库显示造价与英文名双语,可搜索("重型坦克"→heavyTank)
8. move + point 配对向导:拖一条线从区域到目的地,自动建 point 并填 target
9. move 的 unload 开关与"需要载具"提示
10. rotate 触发器:画箭头选方向,自动换算 dir(360.0=一圈)
11. set_team 触发器表单(team 必填,区域内单位换队)
12. unitRemove 表单,并提示"不能指定单位类型"【缺】
13. mapText 表单(文字、颜色、字号预览)【缺】
14. camera_start + zoomTo 放置工具,开局视野预览框【缺】
15. teamTags / teamTagDetect 表单(addTeamTags/removeTeamTags/标签检测),模组联动提示【缺】
16. team_info 表单补全:lockAiDifficulty(-2~3 档位下拉,警告过大值会崩溃)、ai=survival、disabledAI、allyGroup【缺】
17. map_info 表单补全:fog(NONE/map/los)、introText、winCondition 下拉含全部 6 个值、loseCondition 在 1.15+ 被删的警告
18. ai_allow_full_use / disable_unit_ai 区域工具,画区域即生效并显示半透明标记
19. showOnMap 小地图事件开关
20. 属性"全部复制/全部粘贴"(教程里的快捷功能)做成触发器卡片的一键克隆属性
21. 触发器"属性顺序无所谓"→ 保存时统一排序,减少 diff 噪音
22. 触发器颜色标签与分组折叠(按名字家族,如"占32_x")
23. 多选触发器批量改 team / warmup / 颜色
