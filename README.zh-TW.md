# 鏽蝕戰爭地圖編輯器

[中文](README.md) · **繁體中文** · [English](README.en.md) · [日本語](README.ja.md) · [Русский](README.ru.md) · [Español](README.es.md)

為 **鐵鏽戰爭（Rusted Warfare）** 製作的免費編輯器，非官方：**地圖編輯器** 加 **Mod 編輯器**。以 Android 為主，電腦瀏覽器也能用。

![Editor](docs/screenshot-en.png)

- 地圖：選地形直接畫，海岸和懸崖自動銜接；一鍵放出生點和資源池；畫一半再鏡像；觸發器做成「當……就……」卡片；按「能玩嗎？」檢查，多數問題可一鍵修好。
- Mod：用表單改單位，不必碰原始 ini；複製單位、生成變體、數值一鍵縮放；對比表和戰鬥模擬；檢查缺圖、缺音效和錯誤引用，最後打包成 .rwmod。

## 開始使用

1. 到 [Releases](https://github.com/WeaverVictorWings/rw-map-editor/releases/latest) 下載：手機安裝 `rw-map-editor.apk`；電腦解壓 `rw-map-editor-web.zip` 後雙擊 `Start-Editor.bat`。
2. 先開啟一張你已有的鐵鏽戰爭地圖（.tmx），編輯器會從中取出圖塊素材（本專案不附帶遊戲素材）。
3. 建立或編輯地圖，按「能玩嗎？」檢查，再「儲存到遊戲資料夾」進遊戲玩。

首頁可選擇要用 **地圖編輯器**（推薦新手）還是 **Mod 編輯器**，兩邊都有內建的新手教程。
